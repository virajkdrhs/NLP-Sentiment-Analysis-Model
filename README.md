# NLP-Sentiment-Analysis-Model
NLP Sentiment Analysis Model with NLTK VADER and Hugging Face ROBERTA Models

Python based, machine learning model to detect sentiment (The feeling/connation) Amazon reviews show

For Reviews.csv, go to [https://www.kaggle.com/datasets/kazanova/sentiment140?resource=download](url), download and unzip file in project folder

Ensure that Jupyter Notebook file 'NLPModel.ipynb' runs in a python venv kernel.
